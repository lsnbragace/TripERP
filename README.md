# TripERP H0.6.4 — Integrated Planning UX

Versão funcional consolidada para homologação.

## Principais melhorias
- menu lateral recolhível novamente;
- layout responsivo corrigido;
- nome da viagem ativa visível em todas as telas;
- seletor rápido de viagem ativa;
- criação e configuração unificadas;
- datas reais no roteiro dia a dia;
- roteiro inteligente reordenável manualmente;
- alertas de impacto após mudanças de roteiro;
- transportes com tipo, horários, empresa, localizador, status e custos;
- hotéis com check-in/out, quarto, reserva, plataforma, status e custos;
- preservação de itens reservados/pagos quando a rota muda;
- curadoria de experiências com menos resultados e descrição curta;
- Geoapify com diagnóstico;
- orçamento multimoeda BRL/USD/EUR;
- taxas médias e margem cambial;
- campos monetários em passos de 10;
- orçamento consolidado por categoria, destino, dia e status financeiro.

## Limitações
O Roteiro Inteligente ainda não executa otimização geográfica completa com voos e transportes em tempo real. A curadoria de experiências usa dados disponíveis no Geoapify e descrições resumidas geradas a partir da categoria do local.
