# TripERP H0.6.5 — Real Map & Curated Experiences

## Novidades
- mapa real Leaflet + tiles Geoapify;
- mapa em largura total;
- Transportes em card próprio, abaixo do mapa;
- Hospedagens em card próprio, abaixo de Transportes;
- curadoria de até 8 experiências principais;
- nomes internacionais quando disponíveis;
- nome local preservado;
- leitura/transliteração aproximada para alfabetos cirílico, georgiano e armênio;

- todo o núcleo H0.6.4 preservado: viagens ativas, roteiro reordenável, hotéis, transportes, datas e orçamento.

## Observação
A “leitura aproximada” é uma transliteração de apoio e não substitui pronúncia nativa.
