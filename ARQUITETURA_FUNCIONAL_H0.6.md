# Arquitetura Funcional — TripERP H0.6

Fluxo oficial:

Dashboard → Minhas Viagens → Configuração → Destinos → Experiências & Dias → Roteiro Inteligente → Mapa & Logística → Orçamento.

Aprovação é um estado do roteiro, não uma aba.

## Princípios
- cada viagem é um projeto independente;
- destinos não são cadastrados em ordem;
- experiências e dias são decisões interdependentes;
- o roteiro organiza decisões já tomadas;
- o usuário aprova a proposta;
- dados ficam no navegador durante a homologação.
